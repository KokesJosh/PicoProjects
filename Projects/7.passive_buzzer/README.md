# Overview
This project taught me how PWM can be utilized for more than just power, it can also be used for communicating information. 
We utilized a passive buzzer to play the hollow knight theme, but the wrap just determined our volume. To communicate with the 
buzzer what notes we wanted to play, we had to process a note frequency into a div for our pwm to get an output frequency. With the notefrequencies.h file I made, it helped ease the process of 
making a song by just allowing us to use parallel arrays of values.
